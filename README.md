# BIOSTAT 707 Checkpoint 1

Place the 4,000 Challenge 2012 set-a record files under `data/set-a/` and place `Outcomes-a.txt` at `data/Outcomes-a.txt`. Run `pixi install` once to create `pixi.lock`, then render with `pixi run --locked checkpoint1`. The render writes `output/checkpoint1.html`, `output/set-a_long.csv`, `output/set-a_wide.csv`, and `output/missingness_outcome_association.csv`. The raw and derived data are ignored by Git; commit the rendered `output/checkpoint1.html` as required by the course instructions.
